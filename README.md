# Aryan Rathi - CMSC 427 - Homework 11

The focus of this week was to add interactivity and state management to the toy collection app, implementing features like adding, editing, and deleting collections and items. I built on the previous navigation structure and screens to create a fully functional app with proper data persistence across screens using React Context. I also implemented theme customization to allow users to change the app's appearance.

## Project Components

### Design Process

1. State Management Implementation

    - Developed a context-based approach using React's Context API to share data between components

    - Created functionality for adding, editing, and deleting collections and items with proper state updates

    - Implemented budget tracking that accurately reflects the total of all collection budgets

2. Technical Implementation

    - Built a color theme system allowing users to change the app's appearance across all components

    - Removed placeholder collections and implemented full CRUD (Create, Read, Update, Delete) functionality

    - Enhanced UI components to reflect current app state including collected items, budgets, and spending
    
    - Removed the "Find Items" section as requested and implemented "In Development" notifications

    - Update and render quarto document, push changes as needed.
